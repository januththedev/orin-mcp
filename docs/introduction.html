Introduction

Orin MCP connects Orin AI models to the tools you already use — Claude Desktop, Claude Code, Cursor and VS Code. Your client calls Orin through the open Model Context Protocol; you never juggle provider keys.

Four presets, zero keys

Models are discoverable live via orin_list_models. Four presets resolve server-side to free chains under the same quotas as the web app:

  • orin-thinking — max reasoning depth.
  • orin-balanced — speed plus smarts. The default.
  • orin-coding — best free coder, resolved live.
  • orin-cheap — helpers, titles, quick turns.

Two ways to connect

Hosted Streamable HTTP at mcp.orinai.org/api/mcp with a Bearer token — or run npx orin-mcp locally over stdio with ORIN_MCP_TOKEN. Same tools, same scopes, same limits. See Setup.
