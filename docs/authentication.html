Authentication

Every MCP request carries Authorization: Bearer <token> — over Streamable HTTP, or via ORIN_MCP_TOKEN for local stdio. Tokens are scoped at mint:

  • models:read — list presets.
  • chat:generate — run completions.
  • usage:read — inspect usage.

Lifecycle

  • Shown exactly once at mint; only hashes live in the database.
  • Revoke anytime — live sessions die within a minute.
  • A password reset kills every MCP token on the account.
  • Per-token rate limits, request caps and full request logging are always on.
