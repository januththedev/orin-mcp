Setup

  1. Sign in to Orin with your Orin Chat account — no new password, no new service.
  2. Mint an MCP token: Account → MCP tokens → name it, tick scopes, copy once.
  3. Paste one config into your client below (replace PASTE_TOKEN), restart the client, and ask it to use Orin.

Claude Code

claude mcp add --transport http orin \
  https://mcp.orinai.org/api/mcp \
  --header "Authorization: Bearer PASTE_TOKEN"

Cursor (~/.cursor/mcp.json)

{
  "mcpServers": {
    "orin": {
      "url": "https://mcp.orinai.org/api/mcp",
      "headers": { "Authorization": "Bearer PASTE_TOKEN" }
    }
  }
}

VS Code (.vscode/mcp.json)

{
  "servers": {
    "orin": {
      "url": "https://mcp.orinai.org/api/mcp",
      "headers": { "Authorization": "Bearer PASTE_TOKEN" }
    }
  }
}

Claude Desktop (local stdio)

{
  "mcpServers": {
    "orin": {
      "command": "npx",
      "args": ["-y", "github:januththedev/orin-mcp"],
      "env": { "ORIN_MCP_TOKEN": "PASTE_TOKEN" }
    }
  }
}
