Connect in 3 steps Setup guides

Connect

Three steps, five minutes.

Sign in to Orin

Use your Orin Chat account (orinai.org). No new password, no new service.

Mint an MCP token

Account → MCP tokens → name it (Claude Desktop), tick scopes, copy once. Least privilege by default; revoke anytime.

Paste one config

Add the server URL + token to your client below. Enable Orin, then ask your client to use it when appropriate.

Endpoint: https://mcp.orinai.org/api/mcp (Streamable HTTP) · Auth: Authorization: Bearer <token> · Local alternative: npx orin-mcp over stdio with ORIN_MCP_TOKEN.

Clients

Paste, restart, ask.

Verified standard MCP configuration shapes. Replace PASTE_TOKEN with your minted token.

Claude Desktop

# Option A — no JSON: Settings → Connectors → Add custom
# connector → paste https://mcp.orinai.org/api/mcp
# (paid plans; sign in with your MCP token when asked)

# Option B — guaranteed on every plan: run Orin locally
# via stdio (claude_desktop_config.json), then restart Claude
{
  "mcpServers": {
    "orin": {
      "command": "npx",
      "args": ["-y", "github:januththedev/orin-mcp"],
      "env": { "ORIN_MCP_TOKEN": "PASTE_TOKEN" }
    }
  }
}

Claude Code

# terminal — adds an HTTP MCP server to scope
claude mcp add --transport http orin \
  https://mcp.orinai.org/api/mcp \
  --header "Authorization: Bearer PASTE_TOKEN"

Credentials

Least privilege, always.

Tokens are scoped at mint (models:read, chat:generate, usage:read), shown once, hashed at rest, revocable instantly — revocation kills live sessions within a minute. A password reset kills every MCP token on the account. Per-token rate limits, request caps, and full request logging are always on.
